# ModuDesk 0.8.1 使用与迁移

## 启动

Windows：运行 `ModuDesk_0.8.1_x64-setup.exe` 安装。也可直接运行构建目录的 `modudesk.exe`。
Web：在仓库根目录执行 `npm ci`、`npm run build`、`npm start`，打开 `http://localhost:8080`。
启动器优先使用 `apps/web/dist`。端口占用时会停止并提示，不会自动换端口。

浏览器的数据按协议、主机名和端口分别存放。请始终使用 `localhost:8080`，不要交替使用 `127.0.0.1`、其他端口或无痕窗口。浏览器同时只允许一个工作台窗口写入数据。

## 先备份，再迁移

1. 在原来使用的浏览器和地址打开新 Web 构建，旧记录会原位保留。
2. 设置 → 数据与备份 → 导出完整备份，保存 `.mpwbackup` 文件。
3. 在桌面版或另一个浏览器打开设置，选择该备份，检查备份日期和附件数。
4. 点击“备份当前数据并恢复”。系统先下载当前数据备份，再恢复所选数据并重新打开。

备份包含 SQLite 数据库、文献 PDF、文件附件、项目关联和布局，不包含 API 密钥。恢复后需重新配置密钥。
导入会校验文件 SHA-256、SQLite 完整性、版本与附件引用；损坏备份不会进入恢复步骤。目前整包数据上限为 512 MB。

桌面版将 SQLite 快照与附件写入应用数据目录（设置页显示实际位置）。SQL 执行仍采用共享 sql.js 引擎；数据持久化使用原生文件系统和原子文件替换，不依赖浏览器 IndexedDB。恢复使用独立数据代次，成功写完所有文件后才切换；上一代数据保留。Web 恢复在同一 IndexedDB 事务中提交。

状态栏“已保存到本机”表示当前数据库快照已完成持久化。“保存失败”时请点击重试，并保留当前窗口。正常关闭有保存保护；断电、强制结束进程发生在写入完成之前，仍可能丢失尚未确认的输入。

## 科研工作流程

### 0.8.1 可调 AI 助手与论文写作任务

- 右侧助手的上下文来源、模块功能、聊天内容和输入区由三个横向分隔条连接，可上下拖动；“界面布局”页也能精确设置前三个区域的高度，聊天区自动使用剩余空间。
- 每条用户和助手消息都支持选中文字，并提供“复制”按钮。
- 中译英、英译中和中英文润色严格优先处理输入框文本，其次才使用 TeX 选区，不再把整篇论文当成待翻译内容；审稿检查仅在输入为空时回退到当前论文。
- 写作助手复用了本地论文写作项目的完整任务约束，增加自由指令、双语润色、一键写出全部章节，以及摘要、介绍、相关工作、方法、实验分析和结论的独立改写入口。

### 0.8.0 插件市场与开发者中心

- 插件中心升级为插件市场，支持搜索、分类、推荐标记和启用状态管理。
- “开发插件”页可下载起步模板、查看或下载中文教程，并校验 `modudesk.plugin.json` 发布清单。
- 社区插件通过源码审核、自动测试和版本发布进入市场；未经审核的远程代码不会在主界面直接执行。

### 0.7.1 统一上下文 AI 助手

- 系统右侧 AI 助手统一承载邮件、笔记、文献和写作功能，并按当前模块选择上下文。
- 任务、项目和文件页也提供与当前清单、项目资源和文件元数据对应的助手入口。
- 写作模块的翻译、润色、审稿检查、结构解释和章节改写位于右侧；结果可写回本地 TeX 选区。
- 上下文来源可逐项关闭；源码写回不会自动触发 PDF 编译。

### 0.7.0 本地论文写作工作台

在“写作”中选择“打开本地文档”，打开论文主文件 `paper.tex`。左侧编辑源码，点击“保存并编译”后右侧用 PDF.js 连续显示生成的 PDF；普通输入、自动保存和 AI 请求不会刷新 PDF。PDF 支持缩放、横向滑动和可拉伸分栏。双击 PDF 文本时，桌面端通过本次编译生成的 SyncTeX 数据定位到源码行和对应单词。

论文 AI 输出区提供自由指令、中英互译、学术润色、审稿风险检查、结构解释和章节改写。AI 结果先进入输出区；只有点击“替换选区 / 插入光标”才会写入源码，写入后仍需手动编译。DeepSeek-V4-Flash 可在“设置 → AI 服务”选择，预设 endpoint 为 `https://model.jsnu.edu.cn/v1/chat/completions`，模型为 `deepseek-v4-flash`。API key 保存于系统凭据管理器，不进入数据库、备份或仓库。网络模式可选 direct、环境代理、Windows 系统代理或指定代理；自动模式按上述路径依次尝试，Karing 可填写 `http://127.0.0.1:3067`。

本地编译继续按 `\input`、`\include`、图片、文献和模板引用收集依赖；同目录中的无关大文件和大量无关文档不会计入工程限制。SyncTeX 需要 TeX Live 或 MiKTeX 提供 `synctex` 命令。

### 0.6.2 邮件正文宽度稳定

邮件阅读区现在严格使用当前工作区保存的宽度。超长网址、连续英文、发件人地址和预格式化内容会在阅读区内部换行或滚动，不再因打开不同邮件而改变三栏宽度。

### 0.6.1 直接拖拽与 AI 连接修复

侧栏选择“窗口大小”，可调整 TeX/PDF、邮件正文、文献、笔记、写作、项目和 AI 助手等模块内部区域，也可调整工作台停靠区、分栏和浮动窗口尺寸。“左侧导航显示”可逐项决定显示哪些插件入口；自定义后，新安装的插件不会自动加入左栏，隐藏入口也不会卸载或停用插件。

模块界面中的分隔线可直接按住拖动；浮动窗口支持从上下左右边缘及右下角拉伸。桌面版 AI 请求由原生网络层发送，可连接 OpenAI、Anthropic、Google AI、Ollama 和 OpenAI 兼容服务；在 AI 标题栏点击齿轮即可配置并测试。

选择“在工作台悬浮调整”会打开浮动控制面板，可一边查看工作台一边调整。所有尺寸随当前工作区布局自动保存。“恢复默认尺寸”只重置区域、分栏和浮动窗口的尺寸，不移动或关闭模块。

### 0.5.0 连续 PDF 阅读与 LaTeX 预览

- 文献 PDF 和 LaTeX 编译结果均支持整篇连续滚动，页码会随阅读位置更新。
- 文献 PDF 可直接拖选文字创建本地高亮，并从批注栏跳转或删除。
- 桌面端优先使用 `latexmk` 自动完成交叉引用、BibTeX/Biber 和所需编译轮次；未安装时仍使用原兼容流程。

### 0.4.0 校园邮箱与账户管理

已有账户选择“账户设置”，新账户点击“添加账户”，选择 IMAP / SMTP（桌面直连）。腾讯企业邮／校园邮箱预设为 IMAP `imap.exmail.qq.com:993`、SMTP `smtp.exmail.qq.com:465`，两项使用 SSL/TLS。填写完整邮箱地址、登录用户名及密码／客户端授权码。其他学校可修改服务器、端口，并选择 SSL/TLS 或 STARTTLS。

点击“测试 IMAP 和 SMTP”分别检查连接、TLS 和认证；测试不会发送邮件。保存账户后点击“收取邮件”。密码只进入本机凭据库，数据库和工作台备份不包含密码；恢复备份后需重新填写。浏览器版无法直连，需使用 Windows 桌面版。

删除账户需要界面内确认，清除该账户的本机配置、凭据和邮件缓存（包括本机草稿）。服务器上的账户和邮件不会删除。删完所有账户后不会重新生成演示账户。

当前收件范围是配置的接收文件夹最近 50 封，按服务器 UIDVALIDITY 和 UID 去重；单封超过 2 MB 或本次累计超过 20 MB 的邮件会跳过并提示。附件仅显示名称，暂不提供下载。邮件正文按文本显示，纯 HTML 邮件目前显示 HTML 文本源码，不加载远程图片。已读、星标、归档和删除只作用于本机缓存，不回写服务器。SMTP 支持文本正文和多个收件人，服务器确认成功后保存本机已发送记录；不主动上传已发送副本到服务器文件夹。Gmail / Microsoft 365 OAuth 尚未接入。

若腾讯企业邮认证失败，请在网页版确认开启 IMAP/SMTP，并按学校策略使用客户端专用密码；测试界面会显示具体失败阶段。不需要把密码发给维护者。

### 0.3.1 本地 TeX 编译修复

写作 → 选取本地文档 → 选择主 `.tex` 文件 → 选择引擎（中文优先 XeLaTeX）→ “编译并预览 PDF”。编译前自动保存，成功后在编辑器旁显示 PDF，可翻页、缩放和下载；失败时显示日志并清除旧结果。

0.3.2 起，本地编译按文稿中的文件引用递归收集章节、图片、参考文献和本地模板，不再遍历打包整个目录。支持常见的 `input/include`、`includegraphics/graphicspath`、`bibliography/addbibresource`、类与宏包引用及 `import/subimport`。无关 PDF、图片或其他文稿不占用工程限额。仅被收集的依赖受 100 MB / 500 个文件上限约束，超限提示会指出触发文件。

依赖复制到临时目录后编译，不向原工程写入编译中间文件。支持 BibTeX 和 Biber，需本机安装相应工具。引用须位于主文件所在目录或子目录中，不支持目录外文件或符号链接。依赖解析针对常见命令的直接文件名，宏动态拼接的路径可能无法收集，遇到缺失文件可改用直接相对路径并查看编译日志。浏览器版不能启动本机编译器，需使用桌面版。

### 0.3.0 新增功能

- 桌面窗口右上角 ×：选择“最小化到任务栏”“保存并退出”或“取消”。保存失败会保留窗口，解决问题后可重试。
- 文献页：点击“新建文献库”，输入名称后自动选中；“上传本地文档”支持多选 PDF、DOC/DOCX、Markdown、TXT、TeX、HTML、RTF 等。原文件不变，副本归入当前文献库，包含在完整备份中。单文件上限 100 MB；PDF 可阅读，DOCX 和文本可预览并下载，旧版 DOC/RTF 下载后用 Word 打开。
- 写作页：“选取本地文档”支持 DOCX、Markdown、TXT、TeX、BibTeX、HTML。修改后约 450 ms 自动同步，可点击“立即保存”或按 Ctrl+S。切换页面不会中断保存；重新选择同一文件会回到原编辑会话。
- 桌面首次写入在原目录保存 `原文件名.modudesk-随机标识.bak`。每次写入前核对文件内容；被其他程序修改、占用或只读时暂停并显示原因。请避免同时用两个编辑器修改同一文件。
- 同步冲突时可下载编辑副本，然后重新读取本地文件；文件被移走等无法恢复的情况，可“下载副本并断开”后重新选取。不会提供静默强制覆盖。
- DOCX 使用正文段落编辑，保留原 ZIP 中的样式、表格、图片和其他部件；支持常规段落及表格单元格文字。含复杂对象的段落只读，不显示 Word 的页面排版；不支持签名、宏、保护/修订模式文档。旧 `.doc` 编辑前请用 Word 另存为 `.docx`，PDF 在文献库阅读。
- 可编辑文件上限 32 MB，DOCX 解压上限 64 MB；文本支持 UTF-8 和带 BOM 的 UTF-16，保存保留 BOM 及常用换行格式。
- 本地编辑的原文件和 `.bak` 由用户目录管理，不包含在工作台整包备份中。重启后需重新选取文件授权。浏览器版需要支持 File System Access 的 Edge/Chrome；浏览器首次保存会下载原稿备份，权限拒绝时保留草稿并提示。建议使用桌面版进行原文件同步。

1. 文献页导入 BibTeX / RIS / DOI，给文献附加 PDF，阅读并填写笔记。
2. 笔记页记录研究想法；写作页创建富文本文档或 LaTeX 工程。
3. 项目页创建课题，通过标题选择文献、笔记、文档。点击已关联标题即可打开原内容。
4. 写作页点击“插入引用”。富文本当前追加 APA 格式参考文献到末尾；LaTeX 插入 `\cite{key}` 并更新 `references.bib`。目前不提供完整的自动编号引用字段系统。
5. 富文本可导出 DOCX。LaTeX 桌面编译优先以 `main.tex` 为入口，包含工程内 `.tex`、`.bib`，按需运行 BibTeX 并多次编译解析引用。

桌面编译需要 TeX Live 或 MiKTeX。优先查找 PATH，也会探测 Windows 常见安装目录；中文模板使用 `ctexart`。每个编译进程限时 60 秒，失败时显示日志。工作台内部工程接口支持文本 TeX/BibTeX；包含本地图片和模板文件的工程请通过“选取本地文档”打开主 TeX 文件。

## AI

设置中选择服务商，保存接口地址、模型与密钥，再点击“测试已保存的连接”。不同服务商分别保存接口设置。测试只发送测试文本；正常提问按右侧上下文开关选取内容。
Windows 密钥使用系统凭据管理器；Web 使用浏览器加密存储。默认 Demo 是离线演示，不代表真实模型调用。
这轮没有使用个人 API 密钥进行付费调用，实际服务可用性需使用你选择的服务商验收。

## 当前边界

- Gmail / Microsoft 365 真实收发尚未接入，选择后会明确提示；不会伪装成发送成功。
- 多设备同步、移动端、插件市场尚未实现。
- 删除文件不会立即清理共享附件实体，避免其他资源失去附件；后续需增加可恢复的垃圾回收。
- 安装包尚未代码签名；本轮验证构建和运行，不修改原 Arena 分支。
- 建议用一个真实课题连续试用一周，记录阻断流程的问题后迭代。
