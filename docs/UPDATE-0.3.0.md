# ModuDesk 0.3.0 更新说明

## 功能

1. 桌面窗口右上角 × 显示退出/最小化/取消选择。退出前保存工作台和本地编辑文件；有未完成导入、写入错误或文件冲突时保留窗口。
2. 文献库支持页面内创建、批量上传 PDF / Word / Markdown 等文件，自动归入选中的库。新增 DOCX/文本预览、原文件下载；PDF 延用原阅读器。
3. 写作新增“选取本地文档”，支持 DOCX / Markdown / TXT / TeX / BibTeX / HTML。自动回写、Ctrl+S、同步状态、原稿备份、冲突暂停、重新读取和下载副本后断开同步。

文献上传保存的是副本；写作的本地文档同步修改的是选中的原文件。两者互相独立。

## 验证

- 类型检查通过；23 个测试文件、90 项前端测试通过。
- 最后增加的退出/导入保护另外复测相关 5 项用例通过。
- Rust 常规测试 6 项通过，含中文文件路径回写、原稿备份、外部修改冲突及未授权路径拒绝。2 项可选凭据/TeX 集成测试本轮未重跑。
- 浏览器实际创建文献库，批量上传 PDF、DOCX、Markdown 3 个测试文件，均入库；DOCX 正文预览成功。
- Windows x64 NSIS 构建成功。当前工具不能操作桌面窗口，原生文件选择对话框、系统标题栏交互及安装向导仍需用户实际点击验收；关闭选择与编辑器保存逻辑已覆盖自动化测试。

## 使用边界

DOCX 按正文段落编辑，保留原文件样式和其他部件；复杂对象所在段落只读，不提供 Word 页面排版编辑。旧版 DOC 请先转为 DOCX，PDF 用文献阅读器打开。

桌面首次保存会在原文件旁生成 `.modudesk-随机标识.bak`；浏览器首次保存下载备份。工作台完整备份不包含独立的本地写作文件。同步绑定只在本次运行中有效，重启后重新选择文件。

完整操作说明见 [STABLE-GUIDE.md](STABLE-GUIDE.md)。
