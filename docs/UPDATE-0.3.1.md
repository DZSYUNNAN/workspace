# ModuDesk 0.3.1 更新说明

修复本地 TeX 文件打开后缺少编译及 PDF 预览入口的问题。

## 使用方法

安装 0.3.1 桌面版，在写作中选取本地项目的主 `.tex` 文件，选择编译引擎并点击“编译并预览 PDF”。中文文稿默认使用 XeLaTeX。编译前保存当前文稿；成功后可翻页、缩放和下载 PDF，失败时展示编译日志并清除旧预览。

编译会读取主文件所在目录及子目录中的章节、图片、参考文献和模板文件，在临时目录运行，避免在原项目中生成辅助文件。支持自动调用 BibTeX / Biber。原文在其他软件中发生修改时暂停操作，防止覆盖。

需要本机安装 TeX Live 或 MiKTeX。工程应放在独立目录中，外部父目录引用和符号链接不纳入编译；最多读取 500 个支持的文件、合计 100 MB。浏览器版会提示使用桌面版完成本地编译。
