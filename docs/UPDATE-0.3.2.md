# ModuDesk 0.3.2 更新说明

修复本地 TeX 编译因目录中的无关文件而报“工程超过 100 MB / 500 个依赖文件”的问题。0.3.1 会递归打包主文件目录中所有支持格式的文件；0.3.2 改为沿文稿中的文件引用收集依赖，不再扫描整个目录。

- 递归解析常见章节、图片、参考文献、类和宏包引用，支持 `graphicspath`、`import/subimport` 及本地 BibLaTeX 样式。
- 主文件不再重复计入依赖；重复引用和循环引用不重复收集文件。
- 对实际收集的依赖保留 100 MB / 500 个文件上限，超限提示指出具体文件。
- 继续在临时目录编译，保持原文件同步、冲突检查和 PDF 预览行为。

依赖解析支持常见命令中的直接文件名，不执行 TeX 宏展开。动态拼接路径可能需要改用直接相对路径；引用目录外文件和符号链接仍不支持。

## 验证

- 11 项 Rust 常规测试通过，包括无关大文件、无关大量文件、递归依赖、目录边界及实际依赖限额测试。
- 2 项真实 XeLaTeX / BibTeX 编译测试通过。其中本地项目旁包含一个 101 MB 无关 PDF 和 510 个无关 TeX 文件，仍成功生成包含中文、图片和参考文献的 PDF。
- 前端类型检查、93 项测试及生产构建通过。

安装新版后重新选择主 `.tex` 文件并编译即可，无需为排除无关文件而搬动工程目录。
