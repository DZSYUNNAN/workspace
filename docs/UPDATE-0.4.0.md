# ModuDesk 0.4.0 邮箱更新

修复邮箱只能添加、无法删除，以及 IMAP/SMTP 只有占位接口而不能在桌面版连接的问题。

- 新增账户设置与删除确认，删除本机配置、凭据、邮件和草稿，不向远程服务器发出删除指令。
- 新增服务器、端口、加密方式、登录用户名和客户端密码配置；保留已有账户，可直接补全设置。
- 新增腾讯企业邮／校园邮箱预设：IMAP `imap.exmail.qq.com:993`、SMTP `smtp.exmail.qq.com:465`，均使用 SSL/TLS。
- Rust 原生连接支持 SSL/TLS 与强制 STARTTLS、证书校验、连接超时；连接测试分别返回 IMAP 与 SMTP 结果，不发送邮件。
- 新增最近邮件收取、UID 去重、MIME 编码解析和 SMTP 文本发送。发送失败保留编辑内容，不伪造成功记录。
- 修复原有邮件标记 SQL 参数错位，以及切换账户后的刷新使用旧账户的问题。
- 密码通过系统凭据库保存，不进入数据库、备份或命令日志；同一账户的发送、收取与删除操作互斥。

## 验证

前端 26 个测试文件、100 项测试及类型检查通过。Rust 15 项常规测试通过，包括本地模拟 IMAP 协议收件、只读读取、大邮件跳过、中文 MIME 解析和发件地址校验。账户删除、凭据隔离、去重、标记保留、SMTP 拒绝时不创建已发送记录及设置界面也已覆盖测试。

对用户提供的两个腾讯企业邮服务器进行了实际连接与 TLS 握手验证，两项均成功。未使用用户密码，未进行真实账户登录或真实邮件发送；正式认证需在软件内填写账户凭据验证。

## 范围

本次实现桌面账户管理及基本收发。收取接收文件夹最近 50 封邮件，单封 2 MB、本次累计 20 MB，超限邮件提示跳过。附件仅列出名称；HTML-only 邮件显示源码文本。邮件状态管理只影响本机缓存；暂未实现远程移动、删除、附件下载、OAuth 和服务器已发送副本上传。详细配置与使用步骤见 [STABLE-GUIDE.md](STABLE-GUIDE.md)。

协议实现参考：[lettre SMTP 文档](https://docs.rs/lettre/latest/lettre/transport/smtp/struct.SmtpTransport.html)、[mailparse MIME 解析文档](https://docs.rs/mailparse/latest/mailparse/struct.ParsedMail.html)。服务器地址及端口由用户提供。
