# ModuDesk 0.5.0 PDF 阅读与 LaTeX 更新

## 文献阅读

- PDF 页面在同一阅读区内连续排列，可直接滚动浏览全文。
- 页码随滚动位置更新，上一页、下一页、搜索结果和批注均可定位页面。
- 拖选 PDF 文字会创建本地高亮；高亮按比例坐标保存，缩放后仍与文字对齐。
- 批注栏支持查看原文、跳转到所在页和删除高亮。

## LaTeX 写作

- 编译所得 PDF 改为多页连续预览，并保留缩放和页码跳转。
- 桌面端优先调用 TeX Live 或 MiKTeX 的 `latexmk`，自动完成参考文献、交叉引用和必要的重复编译。
- 若系统没有 `latexmk`，会自动退回原有 XeLaTeX、LuaLaTeX 或 PDFLaTeX 多轮编译流程。
