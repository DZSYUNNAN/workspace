# ModuDesk 0.6.2 邮件正文宽度稳定

邮件正文区域现在同时固定 `flex-basis`、宽度和最大宽度，打开不同邮件不会改变分栏。长链接、连续英文、发件人信息、图片、表格和代码块会被限制在正文区域内部。

## 使用方法

1. 从左侧栏打开“窗口大小”。
2. 在“模块内部区域”中调整各模块的分栏尺寸。
3. 在“左侧导航显示”中逐项选择要保留的入口。
4. 在“工作台窗口”卡片中拖动滑块，或输入精确数值。
5. 如需实时观察工作台，点击“在工作台悬浮调整”。

各模块原界面的分隔线上也有可拖拽热区。将鼠标移到边界，出现双向箭头后按住拖动即可；浮动窗口的上下左右四条边和右下角都支持拉伸。

## 支持的尺寸

- 左侧、右侧、顶部和底部停靠区域的宽度或高度。
- 同一区域中多个分栏的横向或纵向占比。
- 每个浮动窗口独立的宽度与高度。
- 本地 TeX 源码/PDF、工作区 LaTeX 源码/PDF 的宽度占比。
- 邮件文件夹宽度和邮件正文区域占比（邮件列表使用剩余空间）。
- 文献列表、PDF 批注栏、笔记列表、笔记编辑/预览、写作文档列表、项目列表和 AI 助手宽度。
- 主导航栏宽度，以及每个插件入口是否在左侧显示。
- 一键恢复默认区域尺寸、50% 分栏比例和 520 × 400 浮动窗口尺寸。

更改会写入当前工作区已有的布局记录，切换工作区后会读取对应工作区自己的尺寸。第一次自定义后，左栏使用明确的显示清单，新安装的插件不会自动加入。隐藏入口不会停用或卸载插件，工作台中已经打开的窗口不受影响。插件不要求文件、网络、凭据或 AI 权限。

## AI 助手连接

Windows 桌面版的 OpenAI、Anthropic、Google AI、Ollama 和 OpenAI 兼容接口现在通过桌面网络层连接，避免 WebView 跨域限制。点击 AI 助手标题栏的齿轮，选择服务，保存 Base URL、模型和 API 密钥，再使用“测试已保存的连接”。离线演示服务无需密钥。
