# ModuDesk 0.7.1 统一上下文 AI 助手

## 新功能

- 移除本地论文写作页内重复的 AI 输出区，论文 AI 统一在系统右侧助手中显示。
- 右侧助手按当前模块读取上下文：邮件页读取当前邮件，笔记页读取当前笔记，写作页读取当前文档或本地 TeX。
- 写作模块向右侧助手提供 TeX 当前选区，并保留中英互译、学术润色、审稿风险检查、论文结构解释和章节改写。
- 邮件模块新增总结邮件、提取待办和期限、起草回复；笔记模块新增总结、结构整理和待办提取。
- 任务、项目和文件模块也接入右侧助手，可安排任务、规划项目、检查风险和分析文件库元数据。
- 右侧 AI 结果可写回当前本地 TeX 选区。写回只保存源码，不自动刷新已编译 PDF。

## 上下文与隐私

- 进入具体模块时，助手只发送该模块当前打开的内容；工作台首页仍可组合已允许的上下文。
- 每个上下文来源都可在右侧助手顶部单独关闭，设置会继续保存在本地。
- 邮件正文、笔记和本地文档只在用户发起 AI 请求时传给当前配置的 AI 服务。

## 验证

- 覆盖普通点击邮件后右侧助手可读取正文、当前笔记上下文、论文任务注册及 TeX 写回不触发 PDF 编译。
- 通过 TypeScript 类型检查、Vitest 全套测试、Web 生产构建和 Rust 测试。
