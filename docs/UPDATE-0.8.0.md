# ModuDesk 0.8.0 插件市场与开发者中心

## 新功能

- 将原有插件中心升级为插件市场，提供市场、已启用、已停用和开发插件四个页面。
- 支持按名称、插件 ID、作者、说明和标签搜索，并按办公、科研、写作和系统分类筛选。
- 市场卡片显示版本、作者、权限、标签、推荐状态和启用状态，可直接启用或停用插件。
- 开发者中心提供可下载的最小插件 ZIP 模板、内置中文教程和发布清单校验器。
- 增加社区发布流程：源码仓库、`modudesk.plugin.json`、自动测试、权限说明和 Pull Request 审核。

## 开发者资源

- `docs/PLUGIN_DEVELOPMENT_GUIDE.md`：从环境准备到插件发布、更新和下架的完整教程。
- `apps/web/src/marketplace/catalog.ts`：市场分类、标签和发布清单校验规则。
- `apps/web/src/marketplace/devkit.ts`：应用内下载的起步模板生成器。
- `PLUGIN_SPEC.md`：运行时接口、权限、生命周期和社区插件发布规范。

## 安全边界

- 0.8.0 的社区插件通过源码审核并随 ModuDesk 版本发布。
- 插件市场不会在主 WebView 中直接执行未经审核或未签名的远程 JavaScript 包。
- 发布清单必须声明权限、许可证和源码仓库，并与运行时清单保持一致。

## 验证

- 覆盖市场搜索与分类、发布清单校验、模板 ZIP 内容和完整应用内开发者入口。
- 通过 TypeScript 类型检查、Vitest 全套测试、Web 生产构建和 Rust 测试。
