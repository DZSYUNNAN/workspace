# ModuDesk 0.8.1 可调 AI 助手与论文写作任务

## 主要变化

- AI 助手的上下文、功能、聊天和输入四区现在可通过三个横向分隔条连续调整高度，尺寸随当前工作区保存。
- 聊天消息允许直接选择文字，并为每条消息提供复制按钮。
- 翻译和润色任务只处理输入框文本；输入框为空时可使用 TeX 选区，但不会再自动提交论文全文。
- 审稿风险检查优先处理输入内容，仅在没有输入和选区时分析当前 TeX；结构解释和章节改写仍使用论文上下文。
- 写作模块增加自由指令、中英文分别润色、一键写出全部章节，以及摘要、介绍、相关工作、方法、实验分析、结论等入口，并迁移参考项目的完整提示词约束。

## 验证

- `npm run check`
- 写作任务输入优先级、提示词内容、剪贴板复制和 AI 内部分隔条 DOM 测试
- Windows Tauri 安装包构建

## 安全与兼容性

- 未加入 API key 或运行时私密文件。
- 现有 AI 提供商和 DeepSeek 配置保持兼容。
- 项目专属的 DKDFusion 名称与源码路径已替换为通用论文上下文，防止对其他论文生成错误要求。
